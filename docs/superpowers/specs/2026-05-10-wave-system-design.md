# Дизайн: Волновая система и победа — «Чайка vs Бутерброд»

**Дата:** 2026-05-10  
**Дедлайн:** 2026-05-11 (день рождения Лёвы)  
**Стек:** vanilla JS + HTML5 Canvas, один файл `index.html`

---

## Цель

Довести игру до логического конца: дать игроку понятную цель (пройти 5 волн),
показывать прогресс в реальном времени (счётчик убитых чаек + номер волны),
наградить победителя званием в зависимости от результата.

---

## Игровой цикл

```
Старт → [Волна 1, 30с] → пауза 3с → [Волна 2, 30с] → пауза 3с
      → [Волна 3, 30с] → пауза 3с → [Волна 4, 30с] → пауза 3с
      → [Волна 5, 30с] → ЭКРАН ПОБЕДЫ
```

- Потерял все жизни на любой волне → обычный Game Over (уже реализован).
- Пережил все 5 волн с ≥1 жизнью → победа.
- Длительность одной волны: 30 000 мс.
- Длительность паузы между волнами: 3 000 мс.

---

## Волны и сложность

Существующая система сложности (`state.timeAlive`) заменяется на волновую.
Каждая волна соответствует определённому набору поведений чаек:

| Волна | Поведение чаек | Реплика при входе в паузу |
|-------|---------------|--------------------------|
| 1 | Одиночные `normal` | *(нет — игра только началась)* |
| 2 | + парные атаки `fromLeft`/`fromRight` | «Ещё одна стая летит!» |
| 3 | + бегуны по парапету `walking` | «Держись, пират!» |
| 4 | + пике `dive`, стаи по 3 | «Бутерброд в опасности!» |
| 5 | Всё сразу, максимальный spawn rate | «Последняя волна!» |

Правило сложности внутри волны: параметры спавна как в текущей ступени сложности,
соответствующей этой волне (волна N ≈ ступень N из 3-х существующих, волны 4–5 = максимум).

## Состояние игры — новые поля

```javascript
state.wave         // текущая волна: 1..5
state.waveTimer    // сколько мс прошло в текущей волне: 0..30000
state.wavePause    // true когда идёт пауза между волнами
state.pauseTimer   // обратный отсчёт паузы: 3000..0
state.killCount    // всего сбитых чаек за игру (инкремент при попадании)
```

Существующий `state.timeAlive` остаётся для совместимости, но логика
сложности спавна читается из `state.wave`, а не из `state.timeAlive`.

## HUD (изменения в верхней панели)

**Было:**
```
[Счёт: 42]                    [❤️❤️❤️]
```

**Станет:**
```
[Счёт: 42  🐦 17]   [Волна 3/5]   [❤️❤️❤️]
```

- Иконка чайки 🐦 + `state.killCount` — добавляется к существующему `.score` div.
- `Волна N/5` — новый элемент по центру HUD, шрифт Caveat.
- Во время паузы `Волна N/5` мигает или меняется на реплику.

## Пауза между волнами

Отображается поверх игры (canvas продолжает рендериться, чайки исчезают,
новые не спавнятся). Элемент — div с абсолютным позиционированием:

```
╔══════════════════════════════╗
║   «Ещё одна стая летит!»    ║
║        Волна 2 из 5          ║
╚══════════════════════════════╝
```

- Шрифт Caveat, размер ~clamp(28px, 6vw, 42px).
- Фон: `rgba(236, 232, 219, 0.92)` (тот же что у overlay в игре).
- Лёгкий rotate(-1.5deg) для рукописного ощущения.
- Мальчик делает nod-анимацию (`triggerBoyNod()`).
- Через 3 000 мс div скрывается, стартует следующая волна.

## Экран победы

Тот же стиль что у стартового экрана и game over. Новый `state` — `'victory'`.

```
╔══════════════════════════════════╗
║          🎉 Победа! 🎉           ║
║                                  ║
║     «Гроза чаек»                ║
║     (звание крупно, ярко)        ║
║                                  ║
║   Счёт: 420   Чаек сбито: 17    ║
║                                  ║
║        [ Ещё раз! ]              ║
╚══════════════════════════════════╝
```

- Заголовок «Победа!» — шрифт Caveat, ~clamp(48px, 10vw, 72px), rotate(-2deg).
- Звание — Caveat bold, ~clamp(32px, 7vw, 52px), цвет `#5A5DAB` (уже используется).
- Счёт и количество — Patrick Hand, обычный размер.
- Кнопка «Ещё раз!» — тот же стиль что существующая кнопка старта.

## Система званий

```javascript
function getTitle(kills) {
  if (kills >= 21) return 'Легенда парка 300-летия!';
  if (kills >= 13) return 'Гроза чаек';
  if (kills >= 6)  return 'Страж бутерброда';
  return 'Защитник';
}
```

| Сбито чаек | Звание |
|-----------|--------|
| 1–5 | Защитник |
| 6–12 | Страж бутерброда |
| 13–20 | Гроза чаек |
| 21+ | Легенда парка 300-летия! |

# Чайка vs Бутерброд 🥪🐦

Простая браузерная игра по рисунку Льва Иоффе (5 лет).

Парк 300-летия в Санкт-Петербурге. Мальчик-пират сел перекусить, а чайки уже знают.
Тапай по чайкам — они улетают.

## 🎮 Играть

→ **https://victorovi4.github.io/seagull-vs-sandwich/** ←

## Разработка

Один файл, без зависимостей. Все ассеты встроены как base64.

```bash
git clone https://github.com/victorovi4/seagull-vs-sandwich.git
cd seagull-vs-sandwich
open index.html             # или python3 -m http.server 8000
```

Полный гайд по архитектуре — в `CLAUDE.md` (Claude Code читает его автоматически).

После правок:
```bash
git add . && git commit -m "..." && git push
# GitHub Pages обновится за ~90 секунд
```

## Лицензия

Рисунок принадлежит Льву Иоффе. Код — свободно для личного использования.

# Чайка vs Бутерброд 🥪🐦

Простая браузерная игра по рисунку Льва Иоффе (5 лет).

Парк 300-летия в Санкт-Петербурге. Мальчик-пират сел перекусить, а чайки уже знают.
Тапай по чайкам — они улетают.

## Как сделано

- Vanilla HTML / JS / Canvas, без зависимостей
- Фон — оригинальная акварель Льва, расширенная программно вверх для пикирования чаек
- Чайки-спрайты вырезаны из его же рисунка через flood-fill контура
- Все элементы синхронизированы по координатам исходного рисунка
- 4 стиля бутерброда переключаются кнопкой в углу
- Лёвина чайка-наблюдательница сидит первые 5 секунд, потом оживает и атакует

## Лицензия

Рисунок принадлежит Льву Иоффе. Код — свободно для личного использования.

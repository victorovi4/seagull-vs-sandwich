# Чайка vs Бутерброд — гайд для Claude Code

## ⚠️ Перед работой с анимацией прочитай `ANIMATION_NOTES.md`

В этом файле — журнал проблем с анимацией персонажей (голова мальчика, чайка-наблюдательница, маски). Там описаны баги, которые мы уже встретили и решили — чтобы не наступать на те же грабли. Особенно важно если будешь трогать `drawBoyHead`, `drawPerchedGull`, `maskLevArea` или координаты в `SRC`.


Игра по рисунку 5-летнего сына (Лев Иоффе): мальчик-пират в Парке 300-летия в СПб, чайки атакуют бутерброд. Браузерная игра, vanilla JS + Canvas, без зависимостей.

## Архитектура

**Один файл — `index.html`** (~550 KB). Содержит HTML, CSS, JS и **все ассеты в base64**:
- Фон сцены (extended sky + Lev's drawing) — JPEG
- Спрайт чайки + флипнутая копия — PNG (вырезаны программно из исходного рисунка)
- Спрайт головы мальчика — PNG (для анимации)

Никакой сборки. Никаких зависимостей. Открыть в браузере = работает.

## Ключевые объекты в коде

### `SRC` — координаты в исходном рисунке (extended bg 1121×1743)

Базовая система координат — пиксели исходного рисунка Лёвы (1121×823), смещённого вниз на `OFFSET_Y = 920` (расширенное небо сверху).

```javascript
SRC.sandwichCenter      // где рисуется бутерброд
SRC.gullPerchCenter     // где сидит чайка-наблюдательница
SRC.boyHeadCenter       // центр головы мальчика
SRC.parapetTop          // верх парапета (y)

// Маски (скрывают то что Лёва нарисовал):
SRC.levSandwichArea / Donor   // Лёвин бутерброд (он же кукуруза)
SRC.levGullArea / Donor       // Лёвина чайка-наблюдательница
SRC.boyHeadArea / Donor       // голова мальчика
```

`*Area` — что замаскировать. `*Donor` — откуда взять чистый patch фона для маскировки.

### Функция `srcToCanvas(sx, sy)`

Преобразует SRC-координаты в canvas-координаты с учётом текущего масштаба (`bgScale`) и смещения (`bgOffsetX/Y`). Используется везде где нужно позиционировать что-то относительно рисунка.

### Маскировка Лёвиных персонажей

`maskLevArea(area, donor, cacheKey, feather)` — вырезает прямоугольник из фона по координатам `donor`, добавляет radial alpha gradient (мягкие края, `feather` ∈ [0, 0.5]), и накладывает на `area`. Это позволяет «заменить» нарисованное Лёвой нашими спрайтами — бутербродом, головой, чайкой-перчедкой.

Кэширует patches в `maskCache`, инвалидация по resize.

### Состояние игры

- `state.gulls[]` — все летающие/идущие чайки
- `state.lives` (3..0), `state.score`
- `state.timeAlive` — для шкалы сложности
- `state.biteProgress` (1..0) — для squash-stretch анимации бутерброда при укусе
- `state.shake`, `state.flash` — экранные эффекты при укусе
- `boyHeadState.startle/nod` (1..0) — анимация головы мальчика
- `perchedGullState` — состояние Лёвиной чайки (`perched` → `taking_off` → `launched`)

### Спавн чаек

Три ступени сложности по `state.timeAlive`:
- 0–15с: одиночные чайки, тип `'normal'`
- 15–30с: + парные атаки `fromLeft`/`fromRight`, бегуны по парапету `'walking'`
- 30+с: + стаи из 3, пике `'dive'`

Типы — параметр в `makeGull({ type: ... })`.

### Бутерброд

Не спрайт, а **процедурный рисунок** на offscreen canvas (`buildSandwich`). 4 стиля переключаются:
- 1: «пирожок» — охра + контур + 3 точки
- 2: акварельная клякса (без контура)
- 3: печенье/булочка с точками
- 4: карандашный овал со штриховкой

Размер уменьшается при укусах (3 lives → 100%, 2 → 72%, 1 → 48%).
Укусы — реальные вырезы через `globalCompositeOperation = 'destination-out'` с зубчатыми штрихами.

## Что бы я подкрутил дальше (если интересно)

1. **Разбить index.html** на отдельные файлы и assets/ папку. Сейчас всё в одном для самодостаточности, но для разработки удобнее раздельно. Потребует локальный HTTP-сервер для тестов (file:// + relative paths не работает из-за CORS).
2. **Сохранение рекордов** в localStorage.
3. **Звуки** — сейчас простые `OscillatorNode`. Можно вырезать настоящие крики чаек.
4. **Power-ups** — например, бутерброд иногда укрепляется (+1 жизнь) если попадаешь в чайку быстро серией.
5. **Адаптация под планшет/десктоп** — сейчас оптимизировано под мобилку. На широких экранах рисунок Лёвы становится слишком маленьким относительно неба.
6. **Облака на параллаксе** — лёгкие облачка плывут в небе.
7. **Туториал** — первая чайка медленно влетает с подсветкой, чтобы было ясно что делать.

## Известные ограничения

- Голова мальчика анимирована, но тело в фоне статично (это сознательное решение — иначе видны inpainting-артефакты вокруг тела на стыке неба и парапета).
- Маска Лёвиной чайки может слегка просвечивать на стыке с парапетом (donor — небо+верх парапета, но если масштаб экрана нестандартный может не идеально совпасть).
- Все размеры в исходных пикселях рисунка Лёвы; на очень узких/широких экранах требуется тонкая настройка `bgScale`.
